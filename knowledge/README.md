# STOXL Local Knowledge Boundary

This folder is the repo-local text-only knowledge foundation for Phase 34A-C.

Canonical source folders:

- `marketing`
- `operation`
- `strategy`
- `brand`
- `archive`

Use `operation`, not `operations`.

Allowed local text extensions:

- `.txt`
- `.md`
- `.json`
- `.yaml`
- `.yml`

Deferred formats:

- `.pdf`
- `.docx`
- `.xlsx`
- `.pptx`
- `.png`
- `.jpg`
- `.jpeg`

Blocked formats:

- `.env`
- `.key`
- `.pem`
- `.p12`
- `.sqlite`
- `.db`
- `.zip`
- `.7z`
- `.exe`
- `.ps1`
- `.bat`

Phase 34A-C does not create embeddings, vector DB indexes, external source ingest, Discord sends, LLM calls, or external execution.
