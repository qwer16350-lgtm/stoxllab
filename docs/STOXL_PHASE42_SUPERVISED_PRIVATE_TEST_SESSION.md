# STOXL Phase 42 Supervised Private-test Session

Phase 42 adds a deterministic supervised private-test session preflight. It is report-only and blocked by default.

The scaffold requires a max reply count, timeout, cooldown, private-test-only mode, deterministic/frozen reply mode, and disabled LLM/RAG/external execution before a later manual phase can consider a supervised session. This bundle does not run a live runtime and sends no Discord messages.
